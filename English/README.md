# Английский с нуля

Веб-приложение для изучения английского с нуля для русскоговорящих: https://iliafreedive-del.github.io/game-rpg/English/

- 26 уроков в 8 разделах: от `am / is / are` до сравнений и связок — с упором на то, как строить предложения.
- Типы заданий: собрать фразу из слов, перевести, послушать и собрать, сказать вслух (распознавание речи), выбрать вариант, вписать слово, найти пары.
- Сессия на 15 минут с таймером: повторение → новый урок → закрепление, пауза при бездействии, «отсечка» в конце.
- Интервальное повторение (1, 2, 4, 8… дней), работа над ошибками, серия дней, календарь, шпаргалка по всем правилам.
- Прогресс хранится в `localStorage`, можно сохранить в файл и перенести на другое устройство. Работает офлайн (service worker).

Без сборки: чистые HTML/CSS/JS-модули. Материал курса — `js/data.js`.
