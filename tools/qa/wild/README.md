# Сценарии проверки походов (Playwright)
Запуск: `python3 -m http.server 8123` в корне игры, затем `node tools/qa/wild/<файл>.mjs`; скриншоты пишутся в `shots/` рядом с местом запуска (создайте папку).
Chromium берётся из `/opt/pw-browsers/chromium-1194`, playwright — из глобального `node_modules` (путь в первой строке файлов).
- `shot.mjs <realm> <depth> <имя> [fort|inside|exit|spawn:тип1,тип2|mob:тип]` — скриншот поля
- `sim.mjs` — бои с командирами и боссами, подсчёт ударов/подмоги/фаз
- `nem.mjs` — цикл немезиса: ноша → смерть → ранг → возврат → убийство → трофей
- `play.mjs` — объяснялка, слабость, итог форта, подписи порталов в деревне
- `town.mjs` — порталы в деревне, окно похода, возврат домой
- `reg.mjs` — регрессия: катакомбы/«Глубины»/деревня грузятся, «снежные» пропсы откатываются
