# Школа фридайвинга — версия на Godot

Открыть: https://iliafreedive-del.github.io/game-rpg/freediving-godot/

Веб-сборка проекта Godot 4.7.2 (рендер Compatibility / WebGL 2, однопоточная — работает на GitHub Pages и в браузере телефона).
Прежняя веб-версия остаётся на своём месте: `/freediving/`.

Внутри: 3D-ныряльщик со скелетом и гибкими ластами, уроки с фазами и паузами движения,
вход в воду с бортика, дак-дайв с одной ноги, библиотека ошибок «неправильно / правильно»,
раздел «Подводная охота», анатомия со слоями и разрезом головы, CO₂/O₂-таблицы с таймером,
тренировка дня, прогресс (сохраняется в браузере).

3D-модели органов и костей: BodyParts3D © The Database Center for Life Science, CC BY 4.0 (упрощены).
Шрифты: Inter (SIL OFL 1.1), DejaVu Sans.
