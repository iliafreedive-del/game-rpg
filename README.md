# Dark Ascent — организованные паки окружения

8 GLB, 49 именованных объектов. Это организация существующей генерации Meshy: геометрия, UV и встроенные текстуры сохранены. Четыре нулевые нормали исправлены для совместимости с импортерами. Новая геометрия не генерировалась.

## Импорт

- GLB содержит отдельный узел и меш для каждого предмета. Названия узлов совпадают с `name` в `asset_manifest.json`.
- Ось вверх — Y. Размеры заданы в метрах, равномерным масштабированием каждого предмета до указанной высоты. Высоты ориентировочные для игры, а не измеренные реальные размеры.
- Начало координат каждого меша находится у основания, по центру габаритов X/Z. Минимальная локальная Y равна 0.
- Узлы расставлены на сетке для просмотра. Для размещения в игре задайте выбранному узлу собственные position/rotation. Вершины уже находятся в локальных координатах предмета.
- Предметы внутри одного пака используют общий встроенный атлас. При извлечении меша сохраняйте его материал и текстуру.

Пример для Three.js после загрузки GLB:

```js
const source = gltf.scene.getObjectByName('tree_acacia_a');
const tree = source.clone();
tree.position.set(12, 0, -8);
tree.rotation.set(0, Math.PI / 3, 0);
scene.add(tree);
```

## Границы этой обработки

Свободные фрагменты сгруппированы по расположению в исходном паке; треугольники не разрезались. Это не ручная реконструкция форм: дефекты исходной генерации и возможные спорные мелкие детали сохраняются. Перед использованием ключевых объектов крупным планом проверьте их в редакторе.

В руинах `ruin_wall_stairs_altar_ensemble` объединяет стену, лестницу и алтарь: они слишком сблизились в исходной модели для уверенного автоматического разделения.

Снижение числа полигонов не выполнялось. Пять объектов превышают 3000 треугольников; точные значения приведены ниже. Модели статические, без рига, коллизий и LOD.
