# DARK ASCENT — Глава I «Пробуждение под катакомбами»

Изометрическая action-RPG для браузера (телефон, планшет, ПК). Движок и графика — собственные, без сторонних библиотек и чужих ассетов. Размер сборки ≈ 8 МБ.

## Быстрый запуск локально

Игра использует ES-модули, поэтому **двойной клик по index.html не сработает** — нужен любой локальный веб-сервер:

```
cd dark_ascent
python -m http.server 8000
```
Откройте http://localhost:8000. С телефона в той же Wi-Fi сети: http://IP-компьютера:8000.

Управление: телефон — джойстик слева, атака и навыки справа (удерживайте атаку — герой сам подойдёт к врагу). ПК — WASD/стрелки, Пробел — атака, 1–4 — навыки, Shift — уклонение, Q/E — зелья, F — действие, I/C/K/J/M — окна, T — свиток возврата.

## Публикация на Cloudflare Pages (бесплатно)

1. Зарегистрируйтесь на dash.cloudflare.com → **Workers & Pages** → **Create** → вкладка **Pages** → **Upload assets** (прямая загрузка, без Git).
2. Назовите проект (например `dark-ascent`), перетащите **содержимое** папки игры (там, где лежит index.html) → **Deploy**.
3. Через минуту игра доступна по адресу `https://dark-ascent.pages.dev`.
4. Обновление: в проекте → **Create new deployment** → загрузить новую версию.
5. Файл `_headers` уже настраивает кеширование ассетов.

Вариант через GitHub: загрузите папку в репозиторий, в Pages выберите **Connect to Git**, Build command — пусто, Output directory — `/`. Каждый push будет публиковаться автоматически.

## Подготовка к Яндекс Играм

1. Консоль разработчика: https://yandex.ru/dev/games/ → **Добавить приложение** → тип «HTML5-игра».
2. Архив для загрузки: ZIP, в **корне** которого лежит index.html (не папка внутри архива).
3. SDK подключается автоматически: `js/platform/platform.js` определяет домен Яндекса и грузит `/sdk.js`. Для проверки вне Яндекса добавьте к адресу `?yandex=1` (только внутри их черновика).
4. Реализовано по требованиям площадки: `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` (пауза при рекламе, сворачивании, окнах), реклама за вознаграждение (`showRewardedVideo`) с выдачей награды только по `onRewarded`, полноэкранная реклама не чаще 1 раза в 4 минуты и только на безопасных переходах, звук глушится при рекламе и сворачивании, облачные сохранения через `player.setData`.
5. **Покупки**: создайте в консоли товары с ID: `starter_pack`, `gold_small` (расходуемые), `bag_expand`, `gold_perk`, `no_ads` (постоянные). Цены задаются в консоли; в игре показывается цена из каталога Яндекса. Выдача покупки сохраняется **до** `consumePurchase`, при старте вызывается восстановление необработанных покупок.
6. Перед отправкой на модерацию сверьтесь с актуальными требованиями (https://yandex.ru/dev/games/doc/ru/concepts/requirements) — они периодически меняются: иконка 512×512, обложка 800×470, скриншоты, описание, возрастной рейтинг.
7. Для других площадок (VK Play, CrazyGames, GameDistribution) достаточно дописать класс-провайдер в `platform.js` по образцу `YandexProvider`.

## Архитектура

```
index.html, css/style.css, manifest.webmanifest
js/main.js               — запуск, титульный экран, главный цикл
js/core/                 — util, iso (камера/проекция), assets (менеджер ресурсов), input, audio (процедурный звук)
js/data/                 — items, skills, enemies, quests (все игровые числа — здесь)
js/world/                — map (коллизии, линия видимости, поиск пути), zone (сборка уровня из JSON)
js/game/                 — ctx (контекст+шина событий), entities (герой, враги+ИИ, NPC), combat, loot,
                           quests, economy, character, stats, items, save (версии+миграции), game (оркестрация)
js/render/renderer.js    — 2D: пол, сортировка по глубине, прозрачность стен у героя, освещение, эффекты (index.js выбирает 2D или 3D)
js/render3d/             — 3D: рендерер, актёры, слой окружения, земля, модели (docs/MODEL_SPEC.md)
js/ui/                   — hud (панели, кнопки, мини-карта), windows (окна), icons
js/platform/             — platform (Яндекс/демо), monetize (реклама, покупки, ежедневки)
assets/maps              — уровни (JSON) и запечённый пол
assets/sprites           — атласы спрайтов (предрендер 3D)
tools/art, tools/level   — генераторы графики и уровней (Python: numpy+Pillow)
```
Мировые координаты — метры (1 клетка = 1 м), экранные — пиксели; перевод только через `Camera`.

Сохранение: `localStorage['dark_ascent_save_v2']`, поле `v` — версия. Миграция из сборки 1.x (`dark_ascent_chapter1_save`) переносит уровень, золото, характеристики, зелья и прогресс первого задания.

## Пересборка графики (по желанию)
```
cd tools/art
python3 build_hero.py && python3 build_monsters.py && python3 build_props.py
cd ../level && python3 levels.py && python3 bake.py
```
Нужны Python 3.10+, numpy, Pillow. Полная сборка ~40 минут на одном ядре.

## 3D-отрисовка (идёт перенос)
По умолчанию деревня и герой-воин рисуются в 3D (Three.js, стиль torch-вида), остальное — прежней 2D-отрисовкой. Принудительно старая графика: добавьте к адресу `?render=2d`. План и состояние: `docs/RENDER3D_PLAN.md`, формат моделей для всего контента: `docs/MODEL_SPEC.md`, проверка моделей: `node tools/check_models.mjs`. Код — `js/render3d/`, выбор отрисовки — `js/render/index.js`.

## Прототип 3D-графики (Three.js)
`lab/three/` — демо-сцена в стилизованном 3D: трава и деревья на ветру, плащ на физике, чиби-герой и мобы. Запуск и план переноса в игру описаны в `lab/three/README.md`, обоснование стиля — в `docs/GRAPHICS_STYLE.md`. В архив для Яндекс Игр папки `lab/`, `docs/` и `tools/` не включаются; `js/render3d/` и `js/vendor/` (three.js, ≈ 0,7 МБ) входят в сборку.
