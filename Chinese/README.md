# Китайский с нуля

Веб-приложение для изучения китайского (путунхуа) с нуля для русскоговорящих: https://iliafreedive-del.github.io/game-rpg/Chinese/

- 25 уроков в 7 разделах: тоны, пиньинь, иероглифы, 是 / 很, 不 / 吗, 的, числа и счётные слова, время, порядок слов, 有 / 在, 想 / 会 / 能, вопросы, 了 / 过, 也 / 都, 因为…所以, 比.
- Над иероглифами — пиньинь с цветными тонами (можно скрыть в настройках). Нажатие на слово — пиньинь, перевод и зачем оно здесь.
- Ответы можно писать иероглифами или пиньинем (с тонами, цифрами или без тонов). Разбор ошибок под типичные ошибки русскоговорящих: 是 перед прилагательным, 不 вместо 没, 吗 с вопросительным словом, место времени и 在 + места…
- Озвучка и распознавание речи на zh-CN, «написать вместо голоса», 15-минутные сессии, повторение, отработка — как в английском курсе. Прогресс свой (`chinese-course-v1`).

Движок общий с `English/`: страница подключает `../English/js/app.js`, а importmap в `index.html` подменяет модули языка (`lang`, `data`, `drills`, `check`, `explain`, `gloss`) на китайские из `js/`.

После правки `js/data.js` или `js/rules.js`: `cd tools && npm i --no-save pinyin-pro@3 && node gen-py.mjs && node check-data.mjs`.
