# Лексикон — игра-дешифровка английского

Отдельная от английского курса игра (своя ссылка: `/game-rpg/lexicon/`, свой прогресс в localStorage `lexicon-game-v1`).
Мир, карты и спрайты взяты из Dark Ascent (корень репозитория) и скопированы в `lexicon/assets/`, чтобы игра ни от чего не зависела.

- `js/words.js` — 92 слова, 23 страницы журнала (по 4 слова с рисунками), служебные слова и имена.
- `js/story.js` — все реплики (английский + русский перевод), предметы, головоломки, цель.
- `js/ui.js` — диалоги с нажимаемыми словами, заметки-догадки, журнал и расшифровка страниц, Эхо-камень, настройки.
- `js/world.js`, `js/render.js`, `js/engine/` — изометрический мир, ходьба по нажатию, свет.

Проверка словаря: каждое английское слово в репликах должно быть в `WORDS`, `FN` или `NAMES`.
