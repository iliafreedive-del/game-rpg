# Гитара с нуля

Мобильное веб-приложение для обучения акустической гитаре с нуля, на русском.
Работает в браузере телефона, ставится на главный экран (PWA) и работает офлайн.

## Что внутри

- **15 уроков по шагам**: устройство гитары и посадка → настройка → правая рука → левая рука → первые ноты и мелодия → аккорды Em, Am, C, G, Dm, E, D → бой вниз, вниз-вверх, четвёрка, шестёрка → перебор → первая песня.
- **Рисунки**: посадка, постановка левой и правой руки, номера пальцев, схемы аккордов, гриф с нотами.
- **Тренажёр боя**: 5 боёв, любой аккорд или последовательность, демо с движением руки, проверка тапами/свайпами и проверка настоящей игры через микрофон, разбор ошибок (спешите, опаздываете, путаете направление, пропуски).
- **Тюнер** через микрофон: авто-выбор струны, стрелка в центах, подсказки «подтянуть/ослабить», эталонный звук.
- **Проверка через микрофон**: какую ноту вы сыграли (и на каком ладу, если не та), чисто ли звучит аккорд (какая струна глушится или звучит лишняя), попадание в такт.
- **Таймеры и план занятий**: занятие на 10–60 минут разбито на этапы (настройка, разминка, урок, повторение, свободная игра), метроном, «смены аккордов за минуту».
- **Прогресс**: минуты за день и 14 дней, серия дней подряд, пройденные упражнения, рекорды. Хранится в браузере (localStorage).

## Запуск

Сборка не нужна, это статические файлы. Микрофон работает только по https или на localhost:

```sh
cd guitar
python3 -m http.server 8000
# открыть http://localhost:8000
```

На GitHub Pages открывается по адресу `https://<user>.github.io/<repo>/guitar/`.

## Файлы

- `js/data.js` — уроки, аккорды, бои (контент правится здесь)
- `js/components.js` — тюнер, проверки, тренажёр боя, таймер
- `js/audio.js` — синтез звука, метроном, микрофон, определение высоты (YIN), хромаграмма, атаки
- `js/svg.js` — схемы аккордов, гриф, рисунки рук
- `js/app.js` — экраны и навигация
