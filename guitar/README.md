# Гитара с нуля

Мобильное веб-приложение для обучения акустической гитаре с нуля, на русском.
Работает в браузере телефона и ноутбука, ставится на главный экран (PWA) и работает офлайн.

## Что внутри

- **19 уроков в 6 ступенях**: первые звуки (устройство, посадка, настройка, открытые струны) → левая рука и ноты (чистая нота, «паучок», мелодии по табулатуре) → первые аккорды (Em, Am, E, Dm, ритм, квадрат) → бой и новые аккорды (C, G, D, A; вниз-вверх, шестёрка, четвёрка с глушением) → перебор (p-i-m-a: четвёрка, восьмёрка, шестёрка, лёгкий F) → песни целиком.
- **Каждый урок**: цель, «зачем это», шаги «как делать», частые ошибки и как их исправить, «секрет», схемы, упражнения по порядку и пункты «можно идти дальше».
- **Схемы**: аккорды с цветными пальцами (1 синий, 2 фиолетовый, 3 оранжевый, 4 розовый), гриф с нотами и пальцами, табулатура, голова грифа с колками, посадка, руки, глушение, пальцы перебора.
- **Упражнения с микрофоном**: открытые струны и мелодии по нотам (подсказывает, какая струна и лад звучат вместо нужных), «найди ноту», аккорд по одной струне (какая струна глухая и почему), аккорд ударом (какой палец не дожат, какая струна лишняя), смены аккордов за минуту, ритм на гитаре.
- **Без микрофона**: «найди струну» на рисунке, «какая струна звучит» на слух, тесты, таймеры с метрономом, запись себя.
- **Тюнер**: голова грифа с колками, сам узнаёт струну, след стрелки, «звук повышается/понижается» пока крутите колок, ручной выбор струны для сильно расстроенной гитары, эталонный звук.
- **Тренажёр боя и песни**: 6 боёв, демо с движением руки, проверка тапами и настоящей игрой, разбор ошибок; «Кукушка», «Звезда по имени Солнце», «Пачка сигарет», Knockin’ on Heaven’s Door, квадрат и четыре аккорда хитов со схемами текущего и следующего аккорда.
- **Прогресс**: минуты за день и 14 дней, серия дней, упражнения, рекорды; занятие на 10–60 минут с этапами.

## Распознавание звука

`js/dsp.js` — чистые функции без браузера (их можно гонять в Node на записях):

- `PitchTracker` — YIN через БПФ, захват ноты без октавных ошибок, слежение за нотой, отличие нового удара от звенящих струн.
- `TunerLogic` — сглаживание (медиана + фильтр «1 евро»), струна не «перескакивает» без нового удара.
- `NoteMatcher` — «сыграйте ноту»: засчитывает только свежую ноту, об ошибке говорит только про струну, дёрнутую после задания.
- `judgeChord` — разбор аккорда по спектру: недостающие и лишние ноты, глухие струны.

Микрофон берётся без шумодава и автоусиления, один канал (у встроенных микрофонов ноутбуков каналы бывают в противофазе), через AudioWorklet.

## Запуск

Сборка не нужна, это статические файлы. Микрофон работает только по https или на localhost:

```sh
cd guitar
python3 -m http.server 8000
# открыть http://localhost:8000
```

На GitHub Pages открывается по адресу `https://<user>.github.io/<repo>/guitar/`.

## Файлы

- `js/data.js` — уроки, аккорды, бои, переборы, песни (контент правится здесь)
- `js/components.js` — тюнер, проверки нот и аккордов, игры на струны, тренажёр боя, таймер, запись
- `js/dsp.js` — анализ звука: высота ноты, атаки, спектр, аккорды
- `js/audio.js` — синтез звука, метроном, микрофон
- `js/svg.js` — схемы аккордов, гриф, табулатура, колки, рисунки рук
- `js/app.js` — экраны и навигация
