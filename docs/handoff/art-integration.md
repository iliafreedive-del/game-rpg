## Как устроены модели (важно для наложения)
- Модели собираются кодом из примитивов: `js/render3d/kit.js` (`part`, `ball`, `tube`, `merge`), без UV-развёрток. Цвет — по вершинам (низ темнее, `top` — цвет верха).
- Фактуры: `js/render3d/textures.js` — `MAT_LAYERS` (рисуются кодом на canvas, собираются в один массив текстур 256 px на телефоне / 384 на ПК), `MAT_SCALE` — повторов на метр. Слой выбирается у детали опцией `{ tex: 'cloth' }` (атрибут `aTex`), накладывается **трипланарно** и тонируется цветом вершин в `js/render3d/toon.js`. Новые серые тайлы `mat_*.png` от GPT логично добавить сюда же как новые слои (загрузить PNG вместо canvas-функции).
- Звери: общая заготовка `js/render3d/models/mob/_beast.js` (`beastModel(kit, C)`), варианты — `beast.js`, `w_wolf.js`, `f_wolf.js`, `w_bear.js`, `w_boar.js` (параметры `C`: `fur`, `furL`, `furLen`, `furDens`, `snout`, `hump`…). Шерсть сейчас — функция `tufts()`: конусы `ConeGeometry` по эллипсоидам. Замена: полоски-«карты» прядей с `fur_*.png` (alphaTest 0.5, двусторонние, без смешивания — дёшево на телефоне), развешенные рядами по тем же эллипсоидам, тон — цветом вершин зверя.
- Скелеты: `_skeleton.js`; боссы: `_boss.js`; упырь: `ghoul.js`; герои: `models/hero/_hero.js`; жители: `models/npc/_villager.js`. Реестр — `js/render3d/registry.js`.
- Наклейки: UV нет → проекция из локального пространства детали (головы, груди, щита): плоская проекция по оси взгляда, вершины за пределами — прозрачны. Варианты: отдельный меш-«оболочка» поверх детали с собственными UV из проекции, или `DecalGeometry` из three.js examples. Все наклейки — в один атлас (одна текстура, один материал).
- Анимации — свои риги в коде моделей (повороты групп), не скелетные; наклейки и пряди надо крепить к тем группам, что двигаются (голова, туловище).
