# 01. Все персонажи — по одной картинке `meshy_<id>.png`

Рост — в метрах, для пропорций (у зверей — высота в холке). Описание — как персонаж должен выглядеть. Узнаваемость сохраняй: улучшай, но не придумывай заново. Ракурс: гуманоиды — строго спереди, **Т-поза, руки пустые** (оружие из описаний ниже рисуй отдельно, по `03_WEAPONS.md`); четвероногие — три четверти (см. `00_PROMPT.md`).
