# Umbrahold на VK Играх и VK Play

Ветка: `claude/vk-platform-1vthl4` (от `integration/all`). Общие правки игры идут в `integration/all`, эта ветка регулярно её подтягивает (`git merge origin/integration/all`). Здесь — только то, что касается площадок VK.

## Как выбирается площадка
Один код на все площадки. Площадку задаёт сборка или адрес:
- `PLATFORM=vk tools/build_zip.sh` (или `vkplay`, `yandex`) — в `index.html` архива пишется `window.__PLATFORM`, игра не ищет и не грузит SDK другой площадки (`boot.js`, `js/platform/platform.js`, `forcedPlatform`).
- Без `PLATFORM` — как раньше, по адресу: домен Яндекса → Яндекс, параметры запуска VK (`vk_app_id`, `vk_platform`) → VK Игры, домен VK Play → VK Play, иначе демо.
- Для проверки в браузере: `?platform=vk`, `?platform=vkplay`, `?platform=demo`.

## VK Игры (vk.com и ok.ru, VK Bridge 3.0.2)
Сверено с документацией dev.vk.ru/ru/games (15 октября 2026): первые шаги, модерация, реклама, платежи, хостинг, параметры запуска, механики.

### Платежи (monetization/digital-goods, api/payments/virtual-goods/vk)
- ❌ Нужен сервер: VK шлёт на него `get_item` (название, цена в голосах, картинка) и `order_status_change` (выдать товар один раз на `order_id`). Клиент — `VKWebAppShowOrderBox { type: 'item', item }`. План: Cloudflare Worker + выдача покупок в игре после ответа.
- На кнопке покупки — цена в голосах. Лимит 3000 голосов в день на игрока. До модерации платежи тестовые (тестировщики платежей — в настройках).
- Пока лавка за рубли в VK скрыта (`hasProduct` = false).

## VK Play (браузерная F2P-игра)
Сверено с documentation.vkplay.ru (17 октября 2026): Free-to-play → Browser Games (JS API, подготовка страницы, платежи, тестирование), «VK Play Review».
Игра — наш сайт в iframe страницы `vkplay.ru/app/<GMRID>`; в адрес площадка добавляет `sign, uid, appid, currency, lang`.

| Требование (чек-лист Testing и VK Play Review) | Состояние | Где |
|---|---|---|
| JS API подключён (`vkplay.ru/app/<GMRID>/static/mailru.core.js` → `iframeApi`), `getLoginStatus` | ✅ (ветка VK) | `js/platform/vkplay.js` |
| Нет кнопки полного экрана | ✅ (ветка VK), на VK Play кнопка и автопереход скрыты | `fullscreen.js` |
| Игра не запускается одновременно в двух вкладках | ✅ (ветка VK): вторая вкладка — «Игра уже открыта в другой вкладке» | `main.js`, `vkplay.js` |
| Нет рекламы, кроме рекламы через API VK Play | ⚠️ в JS API рекламы нет, сторонняя запрещена → на VK Play реклама не показывается. Кнопки «за просмотр» пока остаются и отвечают «видео не досмотрено» — **решить владельцу**: убрать их на VK Play или давать награду без ролика | `monetize.js` |
| Нет сторонней авторизации, двойной авторизации, внешних ссылок, сторонних оплат | ✅ (Яндекс SDK в сборке VK Play не грузится; аналитика разрешена) | |
| Прогресс сохраняется (через вход или на устройстве) | ✅ на устройстве (localStorage) | |
| Адаптивная вёрстка, окно любого размера, 21:9 | 🔍 вёрстка резиновая, на 21:9 не проверял | |
| Сворачивание без зависаний, настройки сохраняются | ✅ | |
| Платежи: `paymentFrame` (рубли, сумма как есть, суммы > 999 ₽) + уведомление на Callback URL с подписью | ❌ нужен сервер (Cloudflare Worker) и секретный ключ; пока лавка за рубли скрыта | |
| Страница игры: название, описание, обложка с логотипом, возрастная плашка, контакты поддержки, без ссылок | владелец (заполняет) | |
| Аккаунт разработчика: анкета, платёжные данные (обязательны даже для бесплатной игры) | владелец | |

Сроки проверки: техническая до 5 рабочих дней, затем маркетинговая до 3. Тест до публикации — тестовые iframe `vkplay.ru/app/<GMRID>/lp/<N>` («Ссылки для тестового iFrame»). Текст всех страниц — project-files/release/vkplay_docs/.

## Что нужно от владельца
- VK Игры: ссылка на сообщество или почту поддержки (требование модерации).
- VK Игры: ID приложения и защищённый ключ (Управление → Настройки), включённые платежи, адрес сервера колбэков (сделаем на Cloudflare), цены товаров в голосах.
- VK Play: решение по кнопкам «за просмотр» (реклама там невозможна); для покупок — секретный ключ из кабинета и адрес Callback URL (сделаем).
