# Чек-лист модерации Яндекс Игр (по памяти, сайт Яндекса из песочницы недоступен — сверить с актуальной документацией)
Сделано в коде:
- пауза и тишина при сворачивании вкладки и по событиям SDK `game_api_pause/resume`; `LoadingAPI.ready()`, `GameplayAPI.start/stop`;
- реклама только на спокойных переходах (возврат в деревню, спуск в катакомбы), не чаще раза в 4 мин, не в бою; награда только за досмотренный rewarded;
- нет внешних ссылок, контекстное меню и зум страницы отключены, обе ориентации экрана работают;
- переименовано: «Путь героя» → «Летопись битв», «Кровавая жатва» → «Жатва Бездны» (похожесть на известные игры и «кровь» в названии).
Проверить вручную в консоли разработчика:
- возрастной рейтинг (скелеты, насилие без крови — обычно 12+/16+), описание и скриншоты без чужих брендов;
- локализация: игра только на русском — ограничить регионы публикации или добавить EN;
- id товаров и цены в каталоге совпадают с `PRODUCTS` в js/platform/platform.js;
- архив: index.html в корне, размер до лимита, загрузка до 10 с на мобильном.
