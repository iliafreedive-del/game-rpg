# Dark Ascent · Art Bible (3D)

Утверждено: основной вариант — `lab/three/torch.html` («Torch-вид»). Все числа живут в одном месте: `js/render3d/style.js` (копия `lab/three/js/style.js`, перенесённая в игру; демо в `lab/three` заморожены как эталон).
Эта страница только описывает решения. Если число расходится с `style.js`, прав `style.js`. Как делать модели по этому стилю: `docs/MODEL_SPEC.md`.

## 1. Суть стиля
Стилизованное тёмное фэнтези в духе Torchlight, но со своим лицом: **«кость, латунь и бездна»**. Чужие персонажи, интерфейс, логотипы и узнаваемые объекты не копируем, берём только общие принципы: гранёные формы, плотные цвета, тёплый свет свечей, бирюзовые акценты склепа. Без текстур: всё рисуется цветом вершин.

## 3. Пропорции
| Персонаж | Рост | Голова | Пропорция | Особенности |
|---|---|---|---|---|
| Герой | 2.0 м | 0.5 м | **1:4** | плечи с наплечниками ≈ 1.4 м, тонкая талия, кисти r≈0.125, меч ≈ 1.3 м, ноги 0.44 + 0.43 м |
| Скелет-воин | ≈ 2.0 м | ≈ 0.45 | ≈ 1:4.5 | шлем-котелок, щит, ржавый меч |
| Упырь | ≈ 1.7 м (сутулый) | ≈ 0.4 | ≈ 1:4 | руки до колен, быстрый |
| Костяной колдун | ≈ 2.5 м с рогами | ≈ 0.4 | ≈ 1:5.5 | парит, посох с орбой |

Герой должен оставаться самым крупным и светлым силуэтом в кадре. Анимация: IK ног (колени), шаг 0.3–0.9 м, ≈ 1.9 цикла/с на бегу (`HERO.stanceFraction = 0.42`), атака в три фазы (замах, выпад, проводка).

## 7. Деревья и окружение
Лиственные кроны и ёлки собраны из **слоёв гранёных листовых пластин** (пятиугольник с приподнятым центром: у каждой грани свой свет). Три вида лиственных (два размера и деревце), ёлки ярусами, редкие мёртвые деревья. Ветер: изгиб в вершинном шейдере плюс шелест. Крупные формы стен и арки — «рубленые» блоки, свечи и кристаллы дают яркие пятна на тёмном фоне.

## 8. Правила читаемости
1. Герой крупнее и светлее окружения, контур и rim-свет не отключаются на высоком и среднем качестве.
2. Акценты только на тёмном: яркие цвета (огонь, Бездна, бирюза) не заливают большие площади.
3. Угроза видна заранее: красное пятно на земле и пульс при замахе мобов, фиолетовое кольцо и растущая орба у колдуна.
4. Попадание читается мгновенно: белая вспышка, искры, хит-стоп, тряска; смерть: всплеск костей, душа Бездны, кольцо.
5. Задние стены не закрывают героя (растворение дизерингом между камерой и героем).
6. Пол остаётся спокойнее, чем персонажи: контраст плит умеренный.
7. На телефоне ничего важного не мельче 1/8 высоты экрана; проверять в портрете 390×844.

| Цель draw calls после SkinnedMesh | ≈ 120 | | | |
| Текстуры, внешние ассеты | 0 | | | |
| Реальные источники света | ≤ 2 | | | |
| Shadow map | нет | | | |
| three.js | локально, `vendor/`, без CDN (Яндекс Игры) | | | |

Основной вклад в draw calls: герой (28 мешей) и мобы (≈ 126 мешей) вместе с обводкой. FPS в песочнице не мерили (программный рендер), нужен прогон на реальных слабых Android. Адаптивное качество: автопонижение, если FPS < 42 первые 5 секунд.
