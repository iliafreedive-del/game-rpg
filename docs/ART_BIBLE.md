# Dark Ascent · Art Bible (3D)

Утверждено: основной вариант — `lab/three/torch.html` («Torch-вид»). Все числа живут в одном месте: `js/render3d/style.js` (копия `lab/three/js/style.js`, перенесённая в игру; демо в `lab/three` заморожены как эталон).
Эта страница только описывает решения. Если число расходится с `style.js`, прав `style.js`. Как делать модели по этому стилю: `docs/MODEL_SPEC.md`.

## 1. Суть стиля
Стилизованное тёмное фэнтези в духе Torchlight, но со своим лицом: **«кость, латунь и бездна»**. Чужие персонажи, интерфейс, логотипы и узнаваемые объекты не копируем, берём только общие принципы: гранёные формы с фасками, плотные цвета, рисованные фактуры, тёплое солнце против холодных теней, тёплый свет свечей, бирюзовые акценты склепа.

**Фактуры (с октября 2026).** Ограничение «без текстур» снято: цвет по-прежнему задаёт вершина, а поверх неё ложится рисованная фактура, которую игра **генерирует на canvas при загрузке** (`js/render3d/textures.js`, внешних картинок нет). Материалы: дерево (волокна вдоль Y — `wood`, вдоль доски — `woodH`), камень-кладка, дранка/черепица, штукатурка, металл, ткань, кора. Накладываются triplanar в пространстве модели по атрибуту вершины `aTex` (в `part(..., { tex: 'wood' })`), поэтому UV не нужны и фактура не «плывёт» на движущихся персонажах. Земля деревни — отдельный шейдер: трава, глина троп, мох, щели брусчатки, рваные шумом края троп, солнечные и тенистые пятна. Видеопамять фактур ≈ 6 МБ, к весу сборки — 0 байт.

Референсы качества: `docs/reference/torchlight_1…4.webp` (только как образец света и плотности, не копировать).

| AO | «по высоте»: низ предметов темнеет у земли до 0.62 к 0.9 м (персонажи 0.72 к 0.55 м) — контакт с землёй без SSAO |

**Постобработка** (`js/render3d/post.js`, числа — `POST` в `style.js`): сцена рисуется в HDR-цель (half float, MSAA 4× на высоком при DPR < 1.5) →
bloom «dual filter» (порог 0.92, мягкое колено 0.35, сила 0.75, 4 ступени; на среднем 3) → итоговый проход: экспозиция 1.25, плёночная кривая тонов (белая точка 4),
раздельное тонирование (тени в холодную бирюзу `#9fc4cc`, света в тёплое золото `#fff0d4`), насыщенность 1.06, виньетка 0.42, лёгкое зерно 0.012.
На низком качестве постобработки нет: сцена идёт прямо на экран, свет ослаблен до 0.8 (без кривой тонов иначе пересвет).

## 7. Деревья и окружение
Лиственные кроны и ёлки собраны из **слоёв гранёных листовых пластин**. Цвет пластины зависит от глубины в кроне и стороны к солнцу: внутри и снизу — тёмный холодный зелёный, сверху и к солнцу — тёплый жёлто-зелёный (как на референсах). Лес за краем карты — облегчённые `tree_0_far`/`tree_1_far`. Ветер: изгиб в вершинном шейдере плюс шелест.
Формы — «рубленые» с фасками (`kit.bbox`), лёгкая кривизна ручной работы (`geo.warp`). Дома: каменный цоколь из блоков, фахверк (столбы, обвязка, раскосы), двускатная крыша с толщиной и свесом, щипцы, конёк, ветровые доски, труба, дверь на петлях, окна с переплётом, ставнями и ящиком цветов, фонарь у двери.
**Плотность:** декор земли расставляется по карте (`PropLayer.scatterDecor`): папоротники, кусты и пни с поваленными брёвнами у кромки леса, цветы пятнами, камешки у троп, грибы под деревьями; у видимых стен домов — бочки, ящики, мешки, поленницы. Трава — пучки по 4 травинки, гуще у краёв троп, реже вдали (LOD по чанкам). Вода — тёмная глубина, рябь, блики.

## 8. Правила читаемости
1. Герой крупнее и светлее окружения, контур и rim-свет не отключаются на высоком и среднем качестве.
2. Акценты только на тёмном: яркие цвета (огонь, Бездна, бирюза) не заливают большие площади.
3. Угроза видна заранее: красное пятно на земле и пульс при замахе мобов, фиолетовое кольцо и растущая орба у колдуна.
4. Попадание читается мгновенно: белая вспышка, искры, хит-стоп, тряска; смерть: всплеск костей, душа Бездны, кольцо.
5. Задние стены не закрывают героя (растворение дизерингом между камерой и героем).
6. Пол остаётся спокойнее, чем персонажи: контраст плит умеренный.
7. На телефоне ничего важного не мельче 1/8 высоты экрана; проверять в портрете 390×844.

## 9. Лимиты нагрузки (High, 1280×720, деревня, замер Chromium + SwiftShader)
Draw calls считаются **за весь кадр**: проход теней + сцена + постобработка (`renderer.info.autoReset = false`). Треугольники — отдельно для основного прохода и для теней.
| Параметр | Лимит | High, деревня с мобами | High, бой вблизи | Low | Телефон 390×844 (High) |
|---|---|---|---|---|---|
| Draw calls за кадр | ≤ 260 | 150–162 | 150 | 74 | 121 |
| Треугольники, основной проход | ≤ 350 тыс. | ≈ 338–348 тыс. | ≈ 292 тыс. | ≈ 210 тыс. | ≈ 256 тыс. |
| Треугольники, тени | ≤ 100 тыс. | ≈ 72–77 тыс. | ≈ 71 тыс. | 0 | ≈ 57 тыс. |
| Shadow map | 1 | 2048² (Med 1024²) | 2048² | нет | 2048² |
| Постобработка | | bloom 4 + цвет + MSAA (Med: bloom 3, без MSAA) | | нет | |
| Декор земли (`QUALITY.decor`) | | 100 % (Med 70 %) | | 35 % | |
| Рисованные фактуры | ≈ 6 МБ видеопамяти, 0 байт в сборке (генерируются на canvas) | | | | |
| Реальные источники света | ≤ 2 точечных + солнце | | | | |
| three.js | локально, `vendor/`, без CDN (Яндекс Игры) | | | | |

Среднее качество включается автоматически на сенсорных устройствах; в песочнице без сенсора отдельно не замерялось. Персонажи после «жёсткого скининга» (`bakeRigid` в `actor.js`): все меши модели с одним материалом сливаются в один `SkinnedMesh`, кости — прежние `Object3D`. Герой: 1 вызов + 1 обводка + 1 в тень вместо 28 + 28 (плюс плащ и оружие). До переделки (без теней и постобработки) было: 254 вызова, 265 тыс. треугольников в бою.
FPS в песочнице не мерили (программный рендер). Адаптивное качество: автопонижение, если FPS < 42 первые 5 секунд; низкое качество выключает тени, постобработку и 65 % декора.
