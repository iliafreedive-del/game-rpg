# Заказ на графику: походы (Фьорды Скъёльда, Старый Лес)

Для команды 3D (стиль — `docs/ART_BIBLE.md`, формат — `docs/MODEL_SPEC.md`; здесь они не менялись). Сейчас в игре **временные** спрайты: перекраска/масштаб существующих моделей (`js/world/wildfloor.js`). Когда придут настоящие, имя атласа берётся из поля `atlas` (`w_<id>`), размер и анимации — ниже. Размеры в метрах (1 клетка = 1 м); герой 2.0 м.

Общее для всех мобов: 8 направлений, клипы **idle** (4 кадра, цикл), **walk** (8, цикл), **attack** (6–9), **hit** (3), **death** (7–10, остаётся лежать). Силуэт читается на снегу/траве, глаза самосветящиеся. Моб никогда не светлее героя в кадре. Контур атаки: ключевой кадр удара (`impact`) — доля клипа, указана в скобках.

## Эффекты и интерфейс
* Эффекты: ледяной снаряд ведьмы, ледяной шип/круг (телеграф `rift` голубой), корни из земли (зелёный), ударная волна босса (лёд / корни), рог войны (золотое кольцо), метель/снег, светляки/болотные огни — частицы (сейчас — программные).
* Иконки: 2 портала (Фьорды/Лес), задания (6+6 — можно общие), предметы за задания: «Шлем-горностай», «Секира берега», «Лук фьорда», «Посох инея», «Тесак атамана», «Лук Рваного Уха», «Посох лесника», «Шапка охотника».
* Портреты боссов 256×256 для плашки босса: Скъёльд, Хозяин Чащи.
* Звук (по возможности): вой волка, рёв ётуна, хрюканье/топот секача, трель рога, свист атамана, скрип корней, треск льда.
