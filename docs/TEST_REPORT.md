## Разрешения — 15 / 15 PASS
iPhone вертикально 390×844, iPhone горизонтально 852×393, iPad 1024×768, ноутбук 1366×768, ПК 1920×1080:
интерфейс не выходит за экран, страница не прокручивается, окна помещаются в экран (прокрутка внутри окна), ошибок нет.

## Исправлено по отзыву игрока (iPhone 15 Pro)
- Поворот телефона ломал вёрстку (всё уезжало влево) → полноэкранная фиксация страницы, размер холста по CSS, пересчёт после поворота с несколькими задержками и сброс прокрутки. Тест: портрет → альбом → портрет, ничего не выходит за экран, прокрутки нет.
- Квест с медальоном: ключ, найденный заранее, теперь всегда засчитывается (восстановление по состоянию саркофага), виден в инвентаре как предмет задания, саркофаг с ключом светится, дверь открывается сама при подходе, трекер показывает шаги 1/3–3/3.
- Непонятно, как ставить навык в кнопку → автоустановка с подсветкой кнопки и подсказкой, кнопки «В кнопку 1–4».
- Джойстик-«шпингалет» убран: невидимый, появляется под пальцем в любой точке левой части; на ПК — движение за мышью.
- Кнопка свитка пересекалась с джойстиком → перенесена к зельям.
- Надевание вещи — двойным нажатием; описание показывается над сумкой.
- Дома: крыши были перевёрнуты, низ дома обрезан → исправлена модель и рендер, дома перерисованы.
- Добыча: вещи больше не сыплются с монстров; только за задания/контракты/покупку, с праздничным окном награды.

## Найдено и исправлено в ходе тестов
- Кнопка «Говорить/Открыть» перекрывала кнопку навыка → вынесена над панелью.
- Первая комната была слишком сложной (герой погибал) → ослаблены скелеты, группа будит только соседей в прямой видимости.
- Ошибка при открытии инвентаря (обращение к окну до создания).
- Джойстик появлялся у края экрана → позиция пересчитывается после показа интерфейса.
- В вертикальной ориентации меню наезжало на полоски здоровья → меню перенесено строкой ниже.
- Полоса босса не показывалась, если босс замечал героя не сам → показывается по состоянию боя.

## Что НЕ проверено автоматически
- Реальные устройства (iPhone Safari, Android Chrome) — только эмуляция в Chromium.
- Реальный Яндекс SDK (реклама/покупки/облако) — проверен только демо-провайдер; нужен черновик в консоли Яндекса.
- Полное ручное прохождение без вспомогательных действий теста (в тесте часть убийств ускорена прямым уроном, герою в небоевых шагах давалась неуязвимость).
- Баланс на длинной дистанции (после главы I) — только расчётно.
