# Охота — задания-тревоги с мини-боссами

## Как это выглядит для игрока

1. Раз в **15 минут** приходит тревога: «⚠ В лесу появился страшный зверь». Слышен рык, всплывает сообщение, рамка таймера мигает красным.
2. Таймер всегда на виду: справа вверху, под золотом.
   - Пока всё тихо: `🎯 Охота через 12:34`.
   - Во время охоты: `⚠ Охота: Лесной Ужас · Опушка Чёрного леса` (красная пульсирующая рамка).
3. Нажатие на таймер открывает **Задания → Охота**. Там слух («никто не знает, что это за тварь…»), описание чудовища и его приёмов, место, пошаговая инструкция «куда идти», награда и кнопка «Отказаться».
4. На земле горят **красные стрелки** (золотые стрелки остаются за сюжетом). В деревне они ведут к нужному порталу, в зоне охоты — прямо к чудовищу. На мини-карте чудовище обведено красным кругом.
5. Под мини-боссом пульсирует кровавый круг, над ним — красное имя, справа — полоса здоровья как у босса.
6. После победы награда **не выдаётся сразу**: на таймере загорается золотое «✔ Охота: … · Сдайте охоту старосте Эдрику», над старостой — «?», красные стрелки ведут к выходу, а в деревне — прямо к нему.
7. Разговор со старостой: он благодарит своими словами (у каждой охоты своя реплика) и вручает награду — золото, опыт, осколки Бездны ◆, зелье и **именной трофей**. Только после этого таймер снова отсчитывает 15 минут.
8. **Пока охота не сдана старосте, новая не появится**: таймер стоит. Отказ от охоты тоже запускает 15-минутный отсчёт. Отказаться нельзя, пока чудовище с вами сражается.

Охота открывается после первого спуска в катакомбы (3-й шаг сюжета). Первая тревога приходит через 2 минуты, дальше раз в 15 минут. Время реальное: если закрыть игру, тревога будет ждать при следующем входе.

## Места

| Место | Зона | Где именно |
|---|---|---|
| Опушка Чёрного леса | деревня | северо-восточный угол, среди деревьев |
| Старое кладбище | деревня | юго-восток, за могилами |
| Катакомбы | катакомбы | один из залов: Преддверие, Оссуарий, Галерея, Пещера, Перекрёсток |
| Глубины | Глубины | этаж от «рекорд − 3» до «рекорд + 1», если герою хватает уровня; этаж помечен ⚠ в окне портала |

## Мини-боссы (только в охотах)

Пока сделано схематично: это перекрашенные и увеличенные модели уже существующих монстров, со своими приёмами. Позже их можно заменить новыми спрайтами (поле `atlas`).

| Мини-босс | Основа | Приёмы | Где |
|---|---|---|---|
| **Лесной Ужас** | пещерный зверь, мшисто-зелёный, ×1.5 | прыжок, удар вокруг себя, ярость | лес |
| **Плакальщица Кладбища** | костяной колдун, призрачно-голубой | телепорт, веер ледяных сгустков, поднимает скелетов | кладбище |
| **Костяной Жнец** | Страж, кроваво-красный | удары конусом и кругом, кровавая волна, ярость | Оссуарий / Галерея / Перекрёсток |
| **Упырья Матка** | упырь, ×1.7 | быстрая, петляет, рожает выводок упырей | Пещера / Преддверие |
| **Чумной Стрелок** | скелет-лучник, ядовито-зелёный | держит дистанцию, веер из 5 стрел, зовёт лучников | Глубины 6+ ур. |
| **Безглазый Охотник** | зверь, фиолетовый | частые прыжки, молния вокруг себя, ярость | Глубины 6+ ур. |
| **Пепельный Лич** | колдун, огненный | огненное кольцо, призыв колдунов, ярость | Глубины 8+ ур. |

Все опасные приёмы показываются заранее красной зоной на земле: из неё можно уйти или увернуться рывком.

## Как добавить новую охоту

Всё в одном файле: **`js/data/hunts.js`**. Код трогать не нужно.

**Шаг 1. Мини-босс** — добавьте запись в `MINIBOSSES`:

```js
mb_swamp_hag: {
  name: 'Болотная Карга', atlas: 'skel_mage',             // чья модель
  tint: 'sepia(1) hue-rotate(80deg) saturate(3)', scale: 1.4, // цвет и размер
  base: 'caster',                                         // поведение: melee / fast / archer / caster / beast / elite
  hp: 230, dmg: [7, 11], elem: 'cold', speed: 2.1, range: 7, keep: 5, cd: 2.3, impact: 0.55,
  xp: 160, gold: [60, 90], armor: 6, radius: 0.45, proj: 'darkbolt',
  abil: {                                                 // любые из четырёх приёмов
    enrage: true,                                         // ярость на 50% здоровья
    summon: { type: 'ghoul', n: 2, cd: 12 },              // призыв: кого, сколько, раз в N секунд
    nova: { r: 3, cd: 9, mult: 1.3, elem: 'cold', c: [120, 200, 255] }, // удар вокруг себя
    volley: { n: 3, spread: 0.3, cd: 7 },                 // веер снарядов (нужен proj)
  },
  desc: 'Что видит игрок в карточке охоты: как бьёт и как с ней бороться.',
},
```

Модели (`atlas`), которые можно брать: `skel_warrior`, `skel_archer`, `skel_mage`, `ghoul`, `beast`, `elite`. Числа — на 1-м уровне монстра, дальше они растут сами.

**Шаг 2. Охота** — добавьте запись в `HUNTS`:

```js
{ id: 'swamp_hag', title: 'Огни над болотом', place: 'forest', boss: 'mb_swamp_hag', minLevel: 4,
  rumor: 'Над болотом за лесом пляшут синие огни. Двое пастухов пошли посмотреть — и не вернулись.',
  elder: 'Огни погасли? Пастухи снова погонят стадо к болоту. Держи награду.',   // реплика старосты при сдаче
  trophy: { slot: 'amulet', name: 'Глаз Карги' } },
```

- `place`: `forest`, `graveyard`, `catacombs` (тогда ещё `rooms: ['cave', 'cross']`) или `depths`.
- `trophy.slot`: `weapon`, `head`, `chest` или `amulet`. Для оружия имя можно задать по классам: `name: { warrior: '…', archer: '…', mage: '…' }`.

**Шаг 3. (по желанию) Новое место** — добавьте его в `PLACES`. Для места в деревне укажите точку `at: [x, y]` (клетки карты `assets/maps/village.json`) и подсказки `steps`.

Награда считается сама по уровню чудовища (`huntReward`). Интервал и задержку первой охоты меняют константы `HUNT_EVERY` и `HUNT_FIRST`.

## Где лежит код

| Файл | Что делает |
|---|---|
| `js/data/hunts.js` | все данные: интервал, места, мини-боссы, охоты, награда |
| `js/game/hunts.js` | таймер, выбор охоты, появление чудовища, призыв свиты, «убит → сдать старосте» (`turnIn`), отказ |
| `js/game/entities.js` → `AI.mini` | поведение мини-босса: базовое поведение + приёмы |
| `js/game/combat.js` | предупреждения и удары `nova` / `volley` |
| `js/render/renderer.js` | цвет и размер, кровавый круг, красные стрелки |
| `js/ui/hud.js` | таймер под золотом и красный круг на мини-карте |
| `js/ui/windows.js` | вкладка «Охота» в окне заданий, диалог сдачи у старосты, пометка ⚠ на этаже в окне Глубин |

Сохранение: `profile.hunt = { nextAt, cur, done, last }`; `cur.slain = true` — чудовище убито, охота ждёт сдачи старосте. Старые сохранения подхватываются сами: поле создаётся при первом обращении.

## Идеи следующих охот

- **Мельник-оборотень** (лес, ночью): `beast` + `summon` волков; трофей — «Жёрнов-оберег».
- **Утопленница колодца** (деревня, у клумбы): `skel_mage`, ледяная `nova`, тянет героя к себе.
- **Палач-отступник** (катакомбы, Арена после главы): `elite` + `volley` топорами.
- **Рой пепельных упырей** (Глубины 11–15): не один босс, а «матка» плюс волны каждые 8 секунд.
- **Двойная охота**: два мини-босса в одном зале, общая полоса здоровья.
- **Цепочка слухов**: после трёх охот в лесу появляется «Хозяин леса» — особая охота с эпическим трофеем.
